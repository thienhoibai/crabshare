# DM Sans

Các file TTF Regular (400), Medium (500), SemiBold (600), Bold (700) được tải từ
[Google Fonts](https://fonts.google.com/specimen/DM+Sans) và đóng gói bằng mục `fonts`
trong `pubspec.yaml`. App dùng family `DM Sans`; không tải font lúc chạy.

Font dùng giấy phép SIL Open Font License 1.1; xem `OFL.txt`.

Nguồn tải: `https://fonts.googleapis.com/css2?family=DM+Sans:wght@400;500;600;700&display=swap`.
